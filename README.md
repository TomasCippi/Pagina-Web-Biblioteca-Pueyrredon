## 📖 Sobre el Proyecto

Este proyecto contiene el código fuente de la página web oficial de la **Biblioteca Pueyrredón Sud**. Diseñado con un enfoque moderno, limpio y amigable, su objetivo principal es acercar la biblioteca a la comunidad, facilitando el acceso a la información, difusión de actividades y permitiendo que los usuarios se comuniquen de manera rápida y sencilla.

## 🚀 Características

- **Diseño Atractivo:** Una interfaz visualmente agradable, intuitiva y directa para que los lectores y vecinos encuentren lo que buscan sin vueltas.
- **Enfoque Comunitario:** Pensado para destacar los servicios y novedades del espacio cultural.

## 🛠️ Tecnologías

- **Maquetado:** Estructura web estándar (HTML / CSS / JS).
